# Carpeta de Imágenes - Lawcrest Legal Group

Puedes subir tus imágenes directamente en esta carpeta (`/public/images/`):

### 📁 Rutas sugeridas para tus archivos:
- Logo oficial: `/public/images/logo.png` (o `.svg`)
- Imagen del Hero: `/public/images/hero.jpg`
- Imágenes de servicios / inmobiliario: `/public/images/servicios/...`

### 💡 Ventaja:
Cualquier imagen que subas aquí estará disponible directamente en la web con la ruta `/images/nombre-de-tu-archivo.ext` (por ejemplo: `<img src="/images/hero.jpg" />`).

También puedes colocarlas en `/src/assets/images/` si prefieres importarlas mediante código.
